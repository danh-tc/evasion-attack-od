FULL EXPERIMENT DESIGN
Spectral Augmentation for Transferable Adversarial Attacks on Object Detection
==============================================================================

1. RESEARCH QUESTIONS
==============================================================================

Q1: Does spectral augmentation (SSA-style) improve black-box transfer of
    adversarial attacks on object detection compared to RRB (OSFD's original)?

Q2: Which frequency bands matter most for cross-architecture transfer?

Q3: Can alternating CNN/ViT surrogates produce perturbations effective
    against both CNN and transformer-based detectors?


2. EVIDENCE SO FAR (from CPU experiments in this session)
==============================================================================

What we verified (15 images, 10 PGD steps, eps=16/255, YOLOv8s surrogate):

  - Spectral augmentation beats RRB on CNN targets:
      v8n (Group A): +0.42 DSR, t=2.23, significant (**)
      v5n (Group B): +0.23 DSR, t=3.23, significant (***)
      y11n (Group B): +0.15 DSR, not significant

  - Both RRB and Spectral fail on RT-DETR (transformer target):
      RRB:      DSR = -0.078 (attack makes detection worse)
      Spectral: DSR = -0.179 (also fails)

  - Loss function changes (OSFD vs FDFD) produce <1% difference.
    Surrogate architecture produces 29,480x more difference than loss function.

  - In the classification literature, SSA and variants (FDT, FDE, FCR) have
    demonstrated strong frequency-domain augmentation for adversarial transfer,
    but none has been applied to object detection.

What these results do NOT tell us (limitations of CPU experiments):

  - Only 10 PGD steps (OSFD paper uses 300). Insufficient optimization.
  - Only eps=16/255. No multi-epsilon comparison.
  - YOLOv8s surrogate, not FRCNN R50-FPN (OSFD's original surrogate).
  - Targets are all YOLO variants or RT-DETR. Missing FCOS, Deformable DETR,
    DINO Swin-L, Mask R-CNN Swin-T (the actual hard targets).
  - Only 15 images. Need thousands for reliable mAP computation.
  - Random-init models in V2 experiment may not reflect pretrained behavior.
  - OSFD loss implementation is simplified (no object-aware masking, no
    adaptive RRB parameters based on bounding box).

4. MODELS
==============================================================================

4.1 Surrogate Models (used to generate adversarial perturbations)

  Primary:    Faster R-CNN with ResNet-50-FPN backbone
              MMDet config: faster-rcnn_r50_fpn_1x_coco
              Reason: same as OSFD paper, enables direct comparison

  Secondary:  RT-DETR-L (for Phase 2 alternating experiment)
              Reason: transformer-based detector available in both
              Ultralytics and MMDet ecosystems

4.2 Target Models (6 models, 3 groups by expected transfer difficulty)

  Group A — In-family (same ResNet-50 backbone, different detection head)
  Expected: easy transfer, DSR > 0.7

    A1: FCOS with ResNet-50-FPN
        MMDet: fcos_r50-caffe_fpn_gn-head_1x_coco
        Paradigm: anchor-free, single-stage
        Why: same backbone as surrogate, tests detection-head transfer

    A2: Deformable DETR with ResNet-50
        MMDet: deformable-detr_r50_16xb2-50e_coco
        Paradigm: transformer decoder on CNN backbone
        Why: same backbone but transformer detection head,
             intermediate difficulty between CNN and full-ViT

  Group B — Near-family (different CNN backbone)
  Expected: medium transfer, DSR 0.3-0.7

    B1: YOLOv3 with Darknet-53
        MMDet: yolov3_d53_8xb8-ms-416-608-273e_coco
        Paradigm: anchor-based, single-stage
        Why: completely different CNN backbone, classic detection model

    B2: YOLOX-L with Modified CSPNet
        MMDet: yolox_l_8xb8-300e_coco
        Paradigm: anchor-free, single-stage
        Why: modern CNN architecture, different from ResNet family

  Group C — Cross-family (Swin Transformer backbone)
  Expected: hard transfer, DSR < 0.3 (this is the frontier)

    C1: Mask R-CNN with Swin-T backbone
        MMDet: mask-rcnn_swin-t-p4-w7_fpn_1x_coco
        Paradigm: two-stage with ViT backbone
        Why: same detection paradigm as surrogate (R-CNN family)
             but different backbone (Swin vs ResNet).
             Isolates backbone architecture effect.

    C2: DINO with Swin-L backbone
        MMDet: dino-5scale_swin-l_8xb2-36e_coco
        Paradigm: full-transformer (ViT backbone + transformer decoder)
        Why: the hardest target. Benchmark paper (Winter et al. 2026)
             showed all existing attacks fail here (mAP drop only 27%).
             This is THE target that matters.


5. ATTACK IMPLEMENTATION
==============================================================================

5.1 OSFD Loss Function (from the original paper)

  Given surrogate backbone B, adversarial image x_adv, clean image x:

    features_adv = B(augment(x_adv))       # features of augmented adversarial
    features_clean = B(x)                    # features of clean image (fixed)

    L = sum over stages i:
        || features_adv[i] - k * features_clean[i] ||^2

  where k = 3 (amplification factor from OSFD paper).

  The loss pushes adversarial features to be 3x the clean features.
  At object locations (high activation), this creates large distortion.
  At vicinity locations (low activation), this amplifies noise.

  Object-aware masking: use detection output of surrogate on clean image
  to identify bounding boxes. Weight loss higher inside boxes.

5.2 Augmentation Strategies (5 methods to compare)

  A) none — No augmentation. Baseline for ablation.

  B) RRB — Original OSFD augmentation.
     Each iteration, independently sample:
       Rotation: uniform(-7, 7) degrees around image center
       Resize: scale factor uniform(0.9, 1.1), resize then pad back
       Blur: Gaussian kernel size 5, sigma uniform(1, 5)
     All three applied sequentially to adversarial image before
     feature extraction.

  C) DIM — Diverse Input Method (Xie et al., CVPR 2019).
     Classification attack baseline adapted for detection.
     Random resize to [0.9, 1.1] of original, then pad to original size.
     Probability 0.7 of applying transform each iteration.

  D) SSA — Spectrum Simulation Attack (Long et al., ECCV 2022).
     Classification SOTA adapted for detection.
     Each iteration:
       1. FFT of adversarial image
       2. Random sampling of spectral coefficients (tuning parameter rho)
       3. Inverse FFT
       4. Gradient computed on transformed image
     Use N=20 spectral copies, average gradients.
     Original SSA paper recommendation: rho = 0.5 for spectrum range.

  E) SRS — Spectral + Resize + Spatial (Proposed).
     Each iteration:
       1. FFT of adversarial image
       2. Random band attenuation: select random radius range [r1, r2],
          attenuate magnitude by factor uniform(0.3, 0.7)
       3. Inverse FFT
       4. Adaptive resize: scale uniform(0.9, 1.1) based on bbox size
       5. Mild rotation: uniform(-5, 5) degrees
     Key difference from SSA: band attenuation (not coefficient sampling),
     combined with detection-aware resize from RRB.

5.3 PGD Attack Parameters

  Epsilon:     8/255, 16/255, 32/255  (3 settings)
  Iterations:  300  (same as OSFD paper)
  Step size:   eps / 150  (half the budget, standard for PGD)
  Norm:        L-infinity
  Momentum:    0.9 (MI-FGSM style, same as OSFD)
  Init:        zero initialization for delta


6. EVALUATION METRICS
==============================================================================

  Primary:
    mAP@0.5         — detection accuracy on adversarial images
    DSR             — Detection Suppression Rate = 1 - mAP_adv / mAP_clean
                      Higher = better attack. Range: (-inf, 1].
                      DSR < 0 means attack is counterproductive.

  Secondary:
    mAP@0.5:0.95    — stricter detection metric
    L-infinity      — maximum perturbation (verify it's within epsilon)
    LPIPS           — perceptual distance (lower = more imperceptible)
    SSIM            — structural similarity (higher = more imperceptible)

  Per-group aggregation:
    DSR_A           — average DSR on Group A targets (in-family)
    DSR_B           — average DSR on Group B targets (near-family)
    DSR_C           — average DSR on Group C targets (cross-family)
    DSR_all         — average DSR on all black-box targets

  Statistical:
    Mean and standard deviation computed per image, then aggregated.
    Paired t-test between methods (paired by image).
    Report p-values. Significance levels: * p<0.05, ** p<0.01, *** p<0.001.


7. EXPERIMENT PHASES

PHASE 1: Single CNN Surrogate (confirms Contribution 1)
------------------------------------------------------------------------

  Surrogate:  Faster R-CNN R50-FPN
  Targets:    All 6 (A1, A2, B1, B2, C1, C2)
  Dataset:    VOC2012 test set (4952 images)
  Epsilons:   8/255, 16/255, 32/255
  Augmentations: none, RRB, DIM, SSA, SRS

  Total attack runs: 5 augs × 3 eps × 4952 images = 74,280 attack generations
  Total evaluations: 74,280 × 6 targets = 445,680 inference runs

  Estimated time:
    Attack generation: ~8 sec/image (300 steps) × 74,280 = ~165 GPU-hours
    Evaluation: ~0.5 sec/image × 445,680 = ~62 GPU-hours
    Total: ~227 GPU-hours ≈ 9.5 days on 1 GPU

  To make feasible in 3 days:
    Option A: Use 3-4 GPUs in parallel (one per augmentation method)
    Option B: Reduce to 1000 images random subset (still statistically robust)
              → 1000 × 5 × 3 × 8 = 33 GPU-hours attack + 8h eval ≈ 1.7 days
    Option C: Reduce to eps=16/255 only, 2000 images
              → 2000 × 5 × 8 = 22 GPU-hours ≈ 1 day

  Recommended: Option B first (1000 images, all eps), then Option C for
  confirmation if needed.

PHASE 1B: Ablation Study for SRS
------------------------------------------------------------------------

  Purpose: understand which components of SRS contribute to improvements.

  Ablation configs (all at eps=16/255, 500 images):

    SRS-full          — complete method (spectral + resize + rotation)
    SRS-no-spectral   — resize + rotation only (≈ simplified RRB)
    SRS-no-resize     — spectral + rotation only
    SRS-no-rotation   — spectral + resize only
    SRS-spectral-only — spectral masking only, no spatial transform

    Spectral band ablation:
    SRS-lowfreq       — attenuate only r < 0.3*max (low-frequency)
    SRS-midfreq       — attenuate only 0.3 < r < 0.7 (mid-frequency)
    SRS-highfreq      — attenuate only r > 0.7*max (high-frequency)
    SRS-dualband      — attenuate both low and high, preserve mid

    Attenuation strength ablation:
    SRS-att-0.2       — attenuate to 20% (aggressive)
    SRS-att-0.4       — attenuate to 40%
    SRS-att-0.6       — attenuate to 60% (mild)
    SRS-att-0.8       — attenuate to 80% (very mild)

  Output: ablation table showing DSR per group for each variant.
  Key question: does low-frequency attenuation specifically help Group C?


PHASE 2: Dual Surrogate (tests Contribution 2)
------------------------------------------------------------------------

  Only run this AFTER Phase 1 confirms spectral augmentation improves
  CNN→CNN transfer. If Phase 1 shows no improvement, Phase 2 is moot.

  Surrogate combinations:
    Config-A: FRCNN R50 only               (CNN single, baseline)
    Config-B: RT-DETR only                  (ViT single)
    Config-C: FRCNN R50 ↔ RT-DETR alternate (proposed)
    Config-D: FRCNN R50 + RT-DETR ensemble  (average gradients, baseline)

  All configs use SRS augmentation (best from Phase 1).
  Epsilon: 16/255 only.
  Dataset: 500 images (sufficient to see trends).

  Alternating schedule for Config-C:
    Option 1: strict alternation (CNN, ViT, CNN, ViT, ...)
    Option 2: 2:1 ratio (CNN, CNN, ViT, CNN, CNN, ViT, ...)
    Option 3: warm-start CNN 100 steps, then alternate remaining 200

  Output:
    Table showing DSR per group for each config.
    Loss curve plot: loss on CNN surrogate + loss on ViT surrogate per iteration.
    Key question: does alternating produce positive DSR on Group C
    WITHOUT significantly degrading Group A/B?


PHASE 3: Paper-Ready Evaluation
------------------------------------------------------------------------

  Run only the winning method from Phase 1+2 on full dataset.

  Full VOC2012 test set (4952 images) or COCO val2017 (5000 images).
  All 3 epsilon values.
  Compare against published OSFD numbers directly.

  Additional analyses:
    Per-class breakdown: which object classes are most/least affected?
    Image difficulty: does method help more on easy or hard images?
    Perturbation visualization: show clean/adversarial/difference maps
    Feature activation maps: visualize what SRS disrupts vs RRB
    Frequency spectrum analysis: FFT of perturbation, compare RRB vs SRS


8. SUCCESS CRITERIA
==============================================================================

  Minimum (enough for a solid paper):
    SRS improves DSR over RRB by >= 5% on average black-box targets.
    SRS does not degrade DSR on any individual group by more than 3%.
    Statistical significance p < 0.05 on at least 3/6 targets.
    SSA (classification method) as baseline shows SRS is not just a
    trivial port (SRS should outperform naive SSA adaptation).

  Strong (top venue):
    SRS improves Group C (transformer targets) DSR by >= 10% over RRB.
    SRS matches or beats RRB on Group A and B.
    Alternating surrogate achieves positive DSR on DINO Swin-L.
    Clear ablation showing which spectral components drive improvement.

  Moonshot (if everything works):
    First method to achieve > 50% mAP drop on DINO Swin-L from
    CNN-based surrogate.


9. PAPER FRAMING
==============================================================================

  If only Phase 1 succeeds (spectral augmentation improves CNN transfer):

    Title direction: "Frequency-Domain Augmentation for Transferable
    Adversarial Attacks on Object Detection"

    Story: SSA-family methods have proven effective for classification
    transfer but have never been adapted for object detection. We analyze
    why OSFD's RRB augmentation works (spatial diversity) and propose SRS
    which adds frequency diversity. We demonstrate significant improvement
    on CNN-based detector transfer. We also provide the first systematic
    study of cross-architecture (CNN→Transformer) detection attack
    transfer, identifying it as an open problem.

  If Phase 2 also succeeds (alternating surrogate helps):

    Title direction: "Bridging the Architecture Gap: Spectral Augmentation
    and Alternating Surrogates for Cross-Architecture Adversarial Attacks
    on Object Detection"

    Story: extends the above with a novel alternating optimization
    strategy that produces perturbations effective against both CNN and
    transformer detectors from a single adversarial image.

  If Phase 2 fails but provides interesting negative results:

    Include as analysis section: "On the hardness of cross-architecture
    transfer" — demonstrating with controlled experiments that the
    architecture barrier is fundamental, not just an optimization issue.
    This is still a valuable contribution as it sets the frontier clearly.

11. RISK MITIGATION
==============================================================================

  Risk: SRS does not beat RRB on full experiment (CPU results were noise).
  Mitigation: SSA baseline will likely still beat RRB (it's proven for
  classification). If SRS specifically fails, pivot to "SSA for detection"
  as the contribution and investigate why SRS modifications hurt.

  Risk: Alternating surrogate diverges or oscillates.
  Mitigation: log loss curves per iteration. If oscillation detected,
  try gradient projection (project ViT gradient onto CNN gradient direction)
  or reduce ViT step weight. Worst case, report negative result.

  Risk: DINO Swin-L is too large to use as surrogate.
  Mitigation: use RT-DETR-L (smaller transformer detector) as ViT surrogate.
  Or Mask R-CNN Swin-T as a compromise (ViT backbone but smaller).

  Risk: MMDetection version incompatibility.
  Mitigation: use mmdet==3.3.0, mmcv==2.1.0, mmengine==0.10.0 (known stable).
  Docker image: open-mmlab/mmdetection:latest as base.

  Risk: VOC2012 test set annotations not publicly available.
  Mitigation: use VOC2007 test set (4952 images, annotations available)
  or COCO val2017 (5000 images). The benchmark paper used VOC2007.
